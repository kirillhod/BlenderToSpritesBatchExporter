# Legacy reference

`blender_to_sprites_batch_exporter_1_2_1.py` - the last single-file version of
the add-on before the package split.

The file is kept for behavior comparison and history. Do not install it at the
same time as the package `../blender_to_sprites_batch_exporter/`: that creates
two add-ons with the same `bl_idname` values and `scene.bts_settings`.
